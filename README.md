# 🧠 Bandit Linux Journey Notes

> A structured learning log of Linux commands and problem-solving through the OverTheWire Bandit wargame.

---

## 📌 About This Repository

This repository documents my journey through the [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) wargame — a series of Linux challenges designed to teach the basics of security and the command line.

The goal isn't to record answers, but to understand:
- how Linux commands actually work
- how to think in terms of data filtering and system navigation
- how to break a problem down step-by-step using terminal tools

> **Note:** In the interest of fair play, this repo focuses on *concepts and reasoning* rather than direct solutions or passwords for each level.

## 🧭 What This Project Focuses On

Instead of memorizing commands, this repo focuses on:
- Understanding *why* a command works, not just that it works
- Recognizing patterns in Linux problem-solving
- Learning how to combine simple tools into workflows
- Building intuition for terminal-based thinking

---

## 🧰 Core Concepts Covered

- File navigation and inspection (`ls`, `cat`, `file`)
- Searching files and directories (`find`)
- Text searching (`grep`)
- Data transformation (`sort`, `uniq`)
- Stream processing and pipes (`|`)
- Decoding and extraction (`strings`, `base64`, etc.)

*(updated as new concepts come up)*

---

## 🚀 Learning Philosophy

> "Don't memorize commands. Learn how to ask Linux better questions."

Each Bandit level is treated as a small puzzle that teaches a deeper system concept — the command is just the surface.
